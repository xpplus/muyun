# 服务器填写指南（脱敏模板）

> 所有示例中的 Token、IP、域名、实例 ID 均为占位符，请替换为你自己的。

## 1. GitHub Codespaces

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | 否 | 备注名 |
| GitHub Token | 是 | 需 `codespace`、`repo`、`user` 权限 |

无需填写机器名/地址/端口/密钥，全部自动发现。

## 2. instabox

| 字段 | 必填 | 示例 |
|---|---|---|
| API Key | 是 | `ibk_xxxxxxxx` |
| API Base URL | 否 | `https://api.instabox.sh/v1` |
| SSH Host | 建议 | `ssh.instabox.sh` |
| SSH 端口 | 建议 | `2222` |
| SSH 用户 | 建议 | `ibssh_xxxxxxxx` |
| SSH 密码 | **不要填** | instabox 免密 |

## 3. 阿里云 ECS / 轻量应用服务器

| 字段 | 必填 | 说明 |
|---|---|---|
| 产品类型 | 是 | 实例 ID 以 `i-` 开头多为 ECS；32 位十六进制多为轻量 |
| AccessKey ID / Secret | 是 | 建议使用只授权 ECS/轻量 的 RAM 子账号 |
| 地域 RegionId | 是 | 如 `ap-northeast-2` |
| 实例 ID | 是 | 控制台实例详情页 |
| SSH 地址/用户/端口/密码 | 否 | 填了才能用终端/代理/文件 |

## 4. 自定义服务器（SSH / 仅 SFTP）

| 字段 | 必填 | 示例 |
|---|---|---|
| 连接方式 | 是 | `SSH 终端` 或 `仅 SFTP` |
| Host | 是 | `example.com` |
| 端口 | 是 | `22` 或 `2222` |
| 用户 | 是 | `root` |
| 密码 | 视情况 | 用密钥则留空 |

### 开关机 URL（可选）

| 字段 | 说明 |
|---|---|
| 请求方法 | GET / POST |
| 开机/关机 URL | 任意返回 2xx 的接口 |
| Headers | 每行 `Key: Value` |
| 开机/关机 Body | 分开填写，便于不同 signal |

示例（Pterodactyl 面板）：

```
POST https://panel.example.com/api/client/servers/<SERVER_ID>/power
Headers: Authorization: Bearer <TOKEN>
开机 Body: {"signal":"start"}
关机 Body: {"signal":"stop"}
```

### 状态 URL（可选）

返回 JSON 中含 `current_state` / `state` / `status` 时自动解析；否则按 HTTP 200 视为在线。

## 5. 跳板机

独立管理，每台云可单独指定。API 请求会经跳板的 SOCKS5 转发。

## 6. 万物密钥库

| 可见性 | AI/MCP 是否可读 |
|---|---|
| 公开 | 总是可读 |
| 秘密 | 仅当「暴露完整凭据」开启 |
| 私有 | 仅 App 内使用 |

## 7. 常见错误

| 提示 | 处理 |
|---|---|
| `该主机未开启 SFTP 服务` | NAS 控制面板启用 SFTP |
| `SSH 认证失败` | 检查用户名/密码/密钥 |
| `网络不通或超时` | 检查端口转发、跳板、手机网络 |
| `端口已被占用` | 更换端口 |
| `无文件访问权限` | 天道 → 天道法则 → 申请所有文件访问权限 |
