# ⚠️ 安全声明

> **项目定位**：以作者自用为主，同时开源供他人学习与技术参考。
> **不建议用于生产环境或重要资产**；作者不提供任何形式的技术支持与问题答复。
> 你可以自行审计、修改并按需使用，风险自负。

牧云是一款**高危运维工具**，具备开关云主机、执行远程命令、读写服务器文件的能力，
并会持有云厂商凭证与 SSH 私钥。使用前请务必了解：

## 1. 无担保

本项目按「现状」提供，**不提供任何形式的安全担保**。作者不对因使用本项目导致的
凭证泄露、数据丢失、服务器损坏或任何直接或间接损失承担责任。

## 2. 未经安全审计

当前版本**尚未经过第三方安全审计**，密钥存储、权限控制等机制仍在完善中。
**不建议在生产环境或存放重要资产的服务器上直接使用。**

## 3. 无遥测、无后门

本项目**不含任何遥测、后门、广告 SDK 或数据回传逻辑**。
所有凭证仅存储于本机，不会上传至任何第三方服务器。
欢迎审计源码验证。

## 4. 合法使用

**严禁用于非法用途。** 请确保你拥有所管理服务器与账号的合法权限，
不得用于未授权的入侵、扫描、爆破或破坏行为。

## 5. 生产环境建议

**本项目明确不建议用于生产环境。** 如你仍要自行尝试，请 fork 后完整审计并加固，例如：

- 使用 RAM 子账号 / 最小权限的云厂商 AccessKey
- 为 SSH 使用专用密钥对，而不是密码
- 开启 MCP Token 校验（默认随机生成）
- 对 AI/MCP 使用「受保护 / 私有」可见性
- 定期导出配置备份，并妥善保管导出文件（明文 JSON）

## 6. 凭据存储现状

| 项 | 实现 |
|---|---|
| 存储位置 | 本机 SharedPreferences（仅 App 私有目录） |
| 加密方式 | **Android Keystore AES-256-GCM**（`data/SecureStore.kt`） |
| 加密范围 | 服务器(entries)、密钥库(vault)、AI 供应商(aiProviders)、跳板(jumpHosts)、aiKey |
| 密钥特性 | 密钥不可导出，卸载/清数据后不可恢复 |
| SSH 主机密钥 | TOFU（首次信任并固定指纹），指纹变化会拒绝连接 |
| 备份 | 需用「导出配置」（明文 JSON，请自行加密保管） |
