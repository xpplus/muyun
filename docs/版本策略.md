# 版本策略

采用语义化版本 `主.次.修订`：

| 位 | 何时 +1 | 示例 |
|---|---|---|
| **主版本** | 不兼容的重大改动（数据格式迁移、架构大改） | 1.x → 2.0 |
| **次版本** | 向下兼容的新功能 | 1.0 → 1.1 |
| **修订号** | 向下兼容的 bug 修复、文案/日志调整 | 1.0.1 → 1.0.2 |

## 当前

当前版本 `1.0.0`，标记为**不稳定版**（功能可用，但接口/行为可能变化）。

- 修 bug → `0.1.8`、`0.1.9` …（每修一批出一个小版本）
- 加功能 → `0.2.0`
- 架构大改/数据迁移 → `1.0.0`

## 发版流程

1. 改代码 → `./build.sh` → `grep '^e: '` 为空
2. 装包烟测：打开 App、切 5 个 Tab、跑一次 AI 工具调用
3. 改 `app/build.gradle.kts` 的 `versionName` / `versionCode`
4. `git commit` → `git tag vX.Y.Z` → `git push --tags`
5. 输出 APK 到 `<输出目录>/牧云-X.Y.Z.apk`
