## 定位

- 作者自用为主，开源供学习与技术参考
- 不提供技术支持，不保证持续维护
- 不建议直接用于生产环境

## 功能
- 多云管理：instabox / GitHub Codespaces / 阿里云 ECS+轻量 / 自定义 SSH+HTTP / 仅 SFTP
- 灵枢：多标签 SSH 终端 + 本机终端，输出可选中复制
- 灵智：多 AI 供应商、模型自动发现、视觉记忆、附件（落盘并告知路径）、工具调用、历史导出
- 须弥：双栏文件（本机↔云机↔Codespaces）、ZIP 解压、批量复制删除、递归下载
- 幽径：多隧道 SOCKS5 代理、端口记忆、测速
- 虚空跳板：独立跳板管理，按云绑定；隧道健康检查 + 失败重试 + 冷却
- 万物密钥库：键值对/文本，三级可见性
- 灵脉 MCP：JSON-RPC over HTTP，AI 与 MCP 共用同一套工具（ToolRuntime）
- 天机录：分类日志（落盘 + 崩溃上下文 + 导出）

## 架构（详细见 docs/架构说明.md）
分层：core / data / cloud / feature / ui
- `MainActivity` 417 行（仅导航与少量组件）
- `MainVm` 约 1900 行（业务编排，逐步瘦身中）
- 20+ 个分层文件，均带中文注释

## 已知限制
- 跳板仅代理 HTTP API，SSH/SFTP 数据流仍直连
- 代理与跳板同机时，代理运行期间暂停自动轮询（避免抢带宽）
- term_read 的 sessionId 随重连变化，建议用机器名或序号引用
- NAS 需自行开启 SFTP 服务

## 安全
- 凭据仅存设备本地 SharedPreferences
- MCP 默认只监听 127.0.0.1，可设 Token（留空=不校验）
- 需要「所有文件访问权限」才能浏览整个手机存储（可自行开启）
